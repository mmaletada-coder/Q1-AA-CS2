# Homework Hero: The Simple Task & Quiz Tracker

## Project Overview
Homework Hero is an app designed to help middle school students keep track of their daily homework, quizzes, and project deadlines[cite: 1]. Instead of forgetting due dates or getting overwhelmed with multiple subjects, this tool lets students organize their schoolwork, view upcoming assignments, and mark them complete as they finish[cite: 1].

## Key Features
* **Assignment Tracking:** Allows students to log task names, subjects, and due dates[cite: 1].
* **Task Status Updates:** Displays all assignments in an easy list and lets users mark tasks as done[cite: 1].

## Built With
